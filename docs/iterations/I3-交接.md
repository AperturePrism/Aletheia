## 2. 交付了什么

| 路径 | 内容 |
|---|---|
| `core/scopekernel/{scope,kernel,parse,server}.go` | 归一化收口（7 类绕过）+ 三重校验（exclude 优先/默认拒绝/限流）+ roe.yaml 解析 + ScopeService gRPC |

resolver 时 fail-closed；3) exclude 永远优先（安全默认）；4) 预算零配置
即拒绝启动（永不熔断的熔断器不允许存在）；5) roe 空 include 是配置错误。

## 4. 新踩的坑

1. **Go RE2 不支持 lookbehind/lookahead** —— M6 §4.2 的 Python 泄漏模式
   `(?<![\w/])` 无法直译；改为独立扫描函数手动排除前驱字符（语义等价 + 单测）。
2. `net.Resolver.LookupIPAddr` 返回 `[]net.IPAddr` 而非 `[]net.IP` ——
   Resolver 接口抽象时注意一层薄适配。
