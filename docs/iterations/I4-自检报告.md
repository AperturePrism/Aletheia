## 4. 自检的三个强制时点（`docs/10` §6）

### 时点 1：写完测试后、跑测试前 —— 问"这些断言真的在验证功能吗"

对 `prism_test.go` 逐条自问：

- `TestRollbackBranchByteIdentical` **不是**恒真断言 —— 它先算父分支
  状态 hash，回滚后**重新计算**并对比。若分支隔离被破坏（某处漏了
  `branch_id` 条件），两次 hash 会不同。**这是真实校验。**
- `TestSnapshotAtReplaysHistoricalState` 对比的是"回放出的 hash"与
  "当时实时算出的 hash"，不是自比自。
- `TestIngestIsIdempotent` 对比的是**重复投递前后**的状态 hash。
