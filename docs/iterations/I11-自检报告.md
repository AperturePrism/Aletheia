## 4. 自检的三个强制时点（`docs/10` §6）

### 时点 1：写完测试后、跑测试前 —— "这些断言真的在验证功能吗"

**`test_aggregate_has_no_filter_parameter` 的断言强度：**

它用 `inspect.signature` 断言 `HarnessRun.aggregate()` **没有任何参数**：

```python
sig = inspect.signature(harness.HarnessRun.aggregate)
params = [p for p in sig.parameters if p != "self"]
assert params == []
```

这条守护的是 M9 §10 的"**全部基准跑全量任务，不做筛选**"。
若有人加了 `category=` 之类的过滤参数，测试立刻失败 ——
而"筛选后报高分"正是评测 Harness 最容易发生的失真。

**`test_failures_and_limitations_are_required` 的断言强度：**

```python
with pytest.raises(TypeError):
    harness.build_report(good_inputs())   # 缺 failures/limitations
```

它断言这两个参数**无法省略**。这是 M9 §2.2 N3（不选择性报告）与
§11 承诺 3（不隐藏）在 API 层面的机械化 —— 调用方不能"忘了写"。

**`test_the_87_percent_trap_is_represented_correctly` 的断言强度：**

它断言基线表**同时**收录 87%（有描述）与 7%（无描述），
且条件字段分别含"有描述"与"去掉描述"。

守护的是 M9 §3 的反面案例：只报 87% 而不带条件，正是那个案例本身。

**`test_zero_denominator_yields_none_not_zero` 的断言强度：**

它断言 0/0 → `None` 且 `sufficient_sample=False`。
若实现改成填 0，"没测"会看起来像"测了且结果为 0"——
对幻觉率而言就是**把未测量伪装成完美达成**。
