### 关键设计决策（实现时定，未改契约）

1. **解析格式选结构化输出**：nmap 用 `-oX` XML（`encoding/xml`），httpx/nuclei 用
   JSONL（`encoding/json`）—— 结构化解析替代正则硬凑（`09` §7 点名的陷阱）。
   JSONL 单行破损降级为 RAW 记录 + unparsed 计数（显式部分解析）；XML 破损
   整体 fail-closed。M1 §4.3 的三个翻车点全部显式处理并有测试。
2. **无损折叠的可行定义**：折叠单元 = 相邻同模板 + 行号连续 + 跨行宽度相同
   + 取值不含分隔符（0x1F）的记录组；组内取值按行序以 0x1F 连接保存。
   `ExpandFolded(Fold(x)) == x` 有 10⁴ 行规模的 round-trip 测试（DoD③ 的机制基础）。
3. **Q6 的正确姿势**：Go protobuf 对 map 字段的默认序列化顺序是**故意随机化的**；
   确定性验证必须用 `proto.MarshalOptions{Deterministic: true}`，
   否则会把序列化器的随机性误判为解析器的非确定性。
4. **EntityDraft 草稿键约定**（M2 落图时消费，M2 实现时须按 05 §3.2 白名单过滤）：
   ASSET=`{addr}`；SERVICE=`{host_addr, port, protocol, service_name?, product?, version?}`；
   ENDPOINT=`{url, method, status_code?}`；DEFECT=`{defect_type, status, severity?, matched_url?, cve?}`。
   其中 `host_addr` / `status_code` / `matched_url` 是草稿扩展键（05 §3.2 无对应槽位），
   M2 转正实体时丢弃或另存。
5. **版本探测与门禁**：`versionCommands` 按工具登记探测命令；未登记的工具
   拒绝门禁。`detected_version` / `tool_version` 输出规范化版本串（如 `7.94.0`）。

## 6. 本次踩到的坑（新增 3 条）

| # | 症状 | 根因 | 解法 / 教训 |
|---|---|---|---|
| 1 | `make test-determinism` exit 5（`46 deselected`） | 该目标 I0 起就对 pytest 用 `-m determinism` 过滤，而 Python 侧从无 determinism 标记测试 —— 恒态失败，形同虚设 | 改为 Go 侧为主体（I1 起有真实确定性测试），Python 行以显式 echo 说明"I0–I1 无确定性对象，I2 恢复 pytest 过滤"。**这不是放宽**：原状态是永假占位，新状态是真实门禁 + 显式声明 |
| 2 | 确定性测试首跑"非确定" | Go protobuf 对 map 字段的**默认序列化顺序故意随机** | Q6 验证必须用 `proto.MarshalOptions{Deterministic: true}`。这个坑会咬到任何做 Q6 的人 |
| 3 | `@ESC@` 占位替换后 ANSI 清洗测试仍失败 | 我把占位符设计成代表整个 CSI 序列，fixture 里又手写了 `[45m`，替换后序列重复 | 占位符只代表**单个 ESC 字节**（0x1B）。教训：fixture 里的占位符语义必须在注释里写清字节级含义 |

**另一条环境事实**：XML 1.0 禁止原始 ESC 字节 —— nmap 的 ANSI 污染只会以
`&#27;` 实体或"污染的非 XML 字节流"形态出现。清洗必须发生在**进入 XML 解析前**
（本次实现如此），否则解析直接失败。

### 9.3 新教训（两条）

1. **rebase merge 与「文档引用 HEAD」机制存在结构性冲突**：每次 rebase 合并后，
   交接文档引用的 HEAD sha 全部失效。脚本的 FAIL 语义会强制发现它（合并后
   main 必红，直到回填）—— 这是设计行为而非缺陷；若想避免，合并 PR 时改用
   merge commit 或 squash 前先接受这个流程成本。
2. **二进制内嵌产物的检测正则**：Vite 哈希含大写字母与连字符
   （如 `index-Scfvx6uw.js`），检测模式必须用 `[A-Za-z0-9_-]*`；
   `[a-z0-9]*` 会得到 0 命中从而误判"未内嵌"。本次差点据此误报发布缺陷。
   另外 `placeholder` 字符串在二进制中恒存在（`cmd/alethd/webplaceholder`
   是包名符号），占位页检测必须匹配**占位页文本**而非包名。
