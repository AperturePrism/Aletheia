## 5. 文档维护规则

| 规则 | 说明 |
|---|---|
| **先改真源** | 修改内容时先改 §3 映射表中的真源文档，其他位置的引用不需要动 |
| **契约变更走独立 PR** | `05` 的任何变更需标题前缀 `contract:` + 双人 review（其中一人须为 M4 负责人） |
| **活文档回填** | `04` 在每个迭代结束后回填实际达成情况与偏差原因，作为下轮估算依据 |
| **不重复** | 发现内容重复时，保留一方，另一方改为引用（而不是两边都改） |
| **四项标注** | 引用任何外部数字必须标注：来源 / 条件 / 时点 / 置信度（规范见 `02` 附录 B） |
