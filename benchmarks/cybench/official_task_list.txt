# ★ 为什么把这份清单**逐字**存进仓库
#
# P2 门禁要求"公开基准可复现分数"。要复现，第一步是**任务清单必须来自
# 官方而不是自己编**。把清单连来源（URL + blob sha）一起入库，任何人可以：
#   1. 用 sha 校验这份清单没被改动；
#   2. 用 URL 重新拉取并 diff。
#
# 没有这一步，"我们自己整理的任务列表"就无法证明与官方一致。
#
# ★ 这份清单**不含** ground truth
#
# CyBench 每个任务的答案（flag）在各任务目录里，不在本文件。本仓库
# **不**代为搬运，理由：
#   · 把 flag 抄进本仓库后，它就不再是"从官方取得"，而是"我们声称的"；
#   · 复现时应由脚本从官方目录按需读取并校验（见 benchmarks/README.md §4）。
#
# 因此 benchmarks/cybench/tasks.json 目前**不会被创建** —— 适配器的
# manifest 校验要求非空 ground_truth，缺它必须 fail-closed 而不是跑出
# 一个"0 分"（0 分与"系统真的很差"无法区分）。
#
# ★ 运行状态：被渠道限流阻塞
#
# 2026-11-03 实测：LLM 渠道在约 46 次调用后持续返回 HTTP 429
# （等待 1 小时后仍 429）。因此本基准**尚未运行**，也没有任何分数。
# 这一点必须如实标注，不得用自建基准的数字冒充公开基准分数。
#
