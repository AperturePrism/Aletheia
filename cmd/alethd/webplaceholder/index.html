Aletheia · WebUI 尚未构建

这是占位页面。真正的 WebUI（React + TypeScript + Vite）构建产物会通过 go:embed 嵌入 alethd 二进制 —— 用户只需一个文件即可运行完整系统（含 UI）。

构建命令：

make build

依据 docs/04-开发总纲 §I0 DoD： WebUI 产物可嵌入单一二进制并正常服务。

看到本页说明 gRPC/HTTP 服务已可启动，只是前端资源尚未构建。 它替代了一个空白页 —— 空白页会让使用者无法判断"UI 坏了"还是"UI 没建"。

本页不含任何业务逻辑。三个核心视图（证据链 / 光圈上下文 / 冲突矩阵）见 docs/06 §6.1，分别在 I2 / I5 / I8 迭代交付 —— 它们是本项目的差异化载体，不可省略（docs/09 R9）。
